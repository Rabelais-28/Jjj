# Cauchemar des Ombres : APK Android

1. Crée un dépôt GitHub (privé ou public) et envoie-y tout ce dossier, y compris `.github`.
2. Onglet **Actions** > **Build APK** > attends environ 5 min (coche verte).
3. Ouvre l’exécution, télécharge l’artefact `cauchemar-apk` (zip), extrais `app-debug.apk`.
4. Sur le téléphone : ouvre l’APK, autorise « sources inconnues », installe.
